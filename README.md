# Сайт alik-recruitment

Это стартовая версия русскоязычного сайта для GitHub Pages.

## Что уже есть
- Адаптивная главная страница.
- Разделы «Условия и выплаты», «Регионы», «Должности», «Контакты».
- Контент вынесен в `data.js`, чтобы его было легко обновлять вручную.
- Не содержит выдуманных регионов, вакансий или подтверждений выплат.

## Как опубликовать
1. Создайте на GitHub публичный репозиторий с точным именем `alik-recruitment.github.io`.
2. Загрузите в корень репозитория файлы `index.html`, `style.css`, `data.js`, `site.js`.
3. В репозитории откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, ветку `main`, папку `/ (root)`, затем Save.
5. После публикации сайт будет доступен по адресу `https://alik-recruitment.github.io/` (если имя аккаунта действительно `alik-recruitment`).

## Как менять публичную информацию сейчас
Откройте `data.js` в репозитории и нажмите Edit (значок карандаша). Измените значения, затем нажмите Commit changes.

Пример:
```js
regions: [
  { name: "Название региона", note: "Статус и дата подтверждения информации" }
],
positions: [
  { name: "Название должности", note: "Краткое описание и требования" }
]
```

Telegram указывается в формате `https://t.me/username`.

## Важно про админ-панель
GitHub Pages — статический хостинг. Он не может безопасно принимать пароль и записывать изменения в файл репозитория сам по себе. Нельзя хранить GitHub Personal Access Token или пароль администратора в браузерном JavaScript: посетители смогут их извлечь.

Поэтому в этой стартовой версии `/admin` ещё не включён. Для безопасной админ-панели без отдельной базы можно добавить серверную функцию (например, Cloudflare Worker), которая проверяет администратора и обновляет JSON-файл в GitHub через секрет, хранящийся только на сервере. Это следующий этап настройки; до его подключения редактируйте `data.js` через GitHub.

## Перед публикацией
- Замените контактные данные.
- Добавляйте только подтверждённые регионы и должности.
- Не размещайте неподтверждённые суммы, гарантии или сроки выплат.
- Укажите ссылки на официальные источники и дату последней проверки условий.
